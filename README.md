# Pasadena Recycling Website

A responsive website for Pasadena Recycling.

## Project layout

- `app/components/` — reusable page sections and interactive pieces
- `app/data/site.ts` — business details and English/Spanish website copy
- `public/assets/` — images, future icons, and source credits
- `public/og.png` — social sharing preview

## Local commands

```bash
pnpm dev
pnpm build
pnpm lint
```

The contact form prepares a message in the visitor's email application. It does not collect or store information on the website.
